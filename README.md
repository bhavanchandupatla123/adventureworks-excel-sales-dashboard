# AdventureWorks Excel Sales Dashboard

An interactive Excel dashboard analysing AdventureWorks sales performance across time, products, customers, and regions.

## Project highlights

- Cleaned and prepared sales data in Excel
- Built PivotTables and PivotCharts for KPI reporting
- Added slicers and an expandable year/month hierarchy for interactive analysis
- Presented key sales trends and business insights in a polished dashboard

## Tools used

Microsoft Excel, PivotTables, PivotCharts, slicers, formulas, data cleaning, and dashboard design.
