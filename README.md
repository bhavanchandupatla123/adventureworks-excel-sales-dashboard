# AdventureWorks Excel Sales Dashboard

An interactive sales-performance dashboard built in Microsoft Excel to turn AdventureWorks transaction data into clear, decision-ready insights.

[![Excel](https://img.shields.io/badge/Microsoft_Excel-217346?style=flat-square&logo=microsoft-excel&logoColor=white)](https://www.microsoft.com/microsoft-365/excel)
[![Portfolio](https://img.shields.io/badge/Portfolio-bhavananalyst.com-0A66C2?style=flat-square)](https://bhavananalyst.com)

## Business objective

The dashboard was designed to help a commercial team monitor performance, identify sales patterns and explore results by time, product, customer and region without working directly with raw data.

## Questions explored

- How does sales performance change by year and month?
- Which products and categories contribute most to revenue?
- Which customers and regions drive performance?
- Where are the strongest and weakest trends?
- How can decision-makers move quickly from headline KPIs to detailed analysis?

## Solution

I prepared the source data, created calculated fields and built a structured reporting layer using PivotTables. I then designed an interactive dashboard with PivotCharts, slicers and an expandable year/month hierarchy so users can move from a high-level view to detailed results.

## Skills demonstrated

- Data cleaning and validation
- Excel formulas and calculated columns
- PivotTables and PivotCharts
- KPI design and performance reporting
- Slicers and interactive filtering
- Date hierarchy and trend analysis
- Conditional formatting
- Dashboard layout and visual hierarchy
- Translating raw data into business insights

## Project file

Download [Bhavan_adventureworks_excel_dashboard.xlsx](Bhavan_adventureworks_excel_dashboard.xlsx) and open it in Microsoft Excel to explore the interactive dashboard.

> For the best experience, use the desktop version of Excel so PivotTables, PivotCharts, slicers and drill-down interactions work as intended.

## How to use the dashboard

1. Open the workbook and navigate to the dashboard sheet.
2. Use the slicers to filter the report.
3. Expand the date hierarchy to move between yearly and monthly views.
4. Select chart elements to explore related results.
5. Clear the slicers to return to the full portfolio view.
